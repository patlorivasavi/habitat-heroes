# Habitat Heroes

Design and build an interactive educational web game for children aged 6–16 based on Sustainable Development Goals SDG 14 (Life Below Water) and SDG 15 (Life on Land).

The game should be a fun, drag-and-drop classification experience where users sort items into the correct environments.

🎯 Core Gameplay:

Display draggable image cards (animals, plants, and pollution items).

Provide three drop zones:

Ocean (Water 🌊)

Forest (Land 🌱)

Recycle Bin (🗑️ for waste items like plastic, oil, trash)

Users drag each item into the correct zone.

🍫 Reward System (Choco Coins):

Replace traditional points with “Choco Coins” (fun, kid-friendly currency).

Correct placement:

Earn +10 Choco Coins 🍫

Show happy animation + sound

Incorrect placement:

Lose -5 Choco Coins

Show a helpful hint explaining the correct answer

🧩 Game Logic:

Track:

Total Choco Coins

Mistakes

Level progress

Provide instant feedback after each action

🌱 Educational Goals:

Teach:

Difference between land and water habitats

Importance of protecting oceans and forests

Awareness about pollution and recycling

🎮 Levels:

Level 1: Basic animals (fish, lion, turtle, tree)

Level 2: Add plants and corals

Level 3: Introduce pollution items (plastic, oil spill)

Level 4: Timed challenge with mixed elements

🎨 UI/UX Requirements:

Bright, colorful, kid-friendly interface

Animated backgrounds:

Moving ocean waves 🌊

Forest with trees and birds 🌳

Smooth drag-and-drop interactions

Visual feedback:

Splash effect for water

Green glow for land

Display Choco Coins clearly at the top with a fun icon 🍫

🏆 Gamification:

Star rating system ⭐

Unlock badges:

“Ocean Protector”

“Forest Guardian”

Progress bar for levels

Optional leaderboard

🧠 Accessibility:

Simple instructions for kids

Large draggable cards

Voice feedback like:

“Yay! You earned Choco Coins!”

“Oops! Try again!”

⚙️ Technical Requirements:

Responsive web app

Prefer React for frontend

Implement drag-and-drop functionality

Maintain game state (Choco Coins, levels, progress)

Clean and modular code

🚀 Bonus Features:

Mini quiz after each level

“Did You Know?” fun facts popup

Sound toggle and background music

Restart and next level buttons

🌍 Scalability:

Design system so new SDG themes and levels can be added later
